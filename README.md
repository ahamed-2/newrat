## 📱 About The App
My Eye is an Android monitoring application developed for **educational purposes only**. It provides features for monitoring device activities with proper consent.

## ⚠️ Legal Disclaimer
**FOR EDUCATIONAL USE ONLY**  
This application should only be used with explicit consent from the device owner. Unauthorized monitoring is illegal.

## ✨ Features
- 📱 **SMS Monitoring**: Real-time SMS forwarding to Telegram
- 🖼️ **Media Scanner**: Automatic media file scanning and backup
- 🤖 **Telegram Integration**: Secure communication via Telegram bot
- 🔄 **Background Services**: Continuous monitoring in background
- 📊 **Statistics**: Track SMS and media counts
- ⚙️ **Customizable Settings**: Flexible configuration options
